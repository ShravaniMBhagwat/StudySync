Study Material Organiser & PYQ Analyser

StudySync

StudySync is a full-stack Python application with machine learning pipelines for subject classification, syllabus parsing, and PYQ frequency analytics.

Checking server status at http://127.0.0.1:5000...

StudySync runs via Flask. Because HTML files in templates/ are server-side Jinja templates, the Python backend must be active to serve pages with complete styling and interactive ML models.

To start the application:
1 Double-click run_app.bat inside this project folder.
2 Or in PowerShell / Command Prompt, run: python app.py
3 Once started, your browser opens automatically to http://127.0.0.1:5000.
